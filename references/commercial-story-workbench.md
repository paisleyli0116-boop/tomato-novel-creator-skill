# 商业故事工作台

本工作台帮助创作者检验一个灵感能否形成读者看得懂、愿意追、可持续兑现的连载故事。商业判断是创作约束与决策依据，不是收益预测。

## 从灵感提炼故事引擎

先保留创作者的原始描述，再确认：

- **读者承诺**：读者点开后将持续获得什么情绪、问题解答或成长体验？
- **主角驱动力**：主角当下想要什么，为什么现在必须行动？
- **核心阻碍**：谁或什么阻挡主角，阻碍为何不能一次解决？
- **选择与代价**：主角如何选择，选择改变了什么？
- **持续引擎**：接下来还能自然产生哪些新的目标、冲突、关系变化或谜团？
- **阶段兑现**：每个阶段给读者什么看得见的进展、反转、关系变化或答案？
- **差异化**：这个创意如何借助人物、价值冲突、设定或叙述视角形成自己的表达？

## 商业适配检查

每个核心剧情方向都检查下列维度。用“有依据 / 待验证 / 有风险”或“强 / 中 / 弱”描述，不用伪精确分数。

| 维度 | 要回答的问题 | 可用信号 |
|---|---|---|
| 题材与读者 | 谁会点开？他们对这一品类的期待是什么？ | 番茄当前分类与标签、公开作品样本、作者明确的目标读者 |
| 开篇与卖点 | 书名、简介、开篇是否快速兑现核心承诺？ | 一句话能否说清主角、矛盾和独特钩子；开篇是否出现具体事件 |
| 冲突引擎 | 主角能否持续作出有代价的选择？ | 一个冲突解决后，是否由人物行动自然产生下一问题 |
| 连载空间 | 中长篇是否有递进而非重复？ | 多阶段目标、升级或关系变化、伏笔与答案的安排 |
| 章节追读 | 读者读完本章后为何继续？ | 本章有进展或情绪回报，结尾产生有意义的新期待 |
| 差异化与原创 | 同类读者能否看出这是独特的一本？ | 人物选择、规则限制、关系结构和表达方式有专属组合 |
| 平台适配 | 题材、内容质量、更新模式和作品信息是否符合当下规则？ | 仅引用最新可查的官方规则；平台算法未知时明确未知 |
| 创作者可执行性 | 作者是否能持续写出该设计所需的素材与更新量？ | 创作时间、资料需求、篇幅、难度、用户明确的写作习惯 |

## 给方向做剧情推演

对每个候选方向，依次回答：

1. 主角此刻要什么？
2. 谁或什么挡住了主角？冲突为什么无法轻易绕过？
3. 主角面临哪两个以上的选择，各自付出什么代价？
4. 选择造成什么可见后果？人物、关系、地位或谜团如何变化？
5. 这一步兑现了什么读者承诺？留下什么新问题？
6. 这个引擎能产生后续阶段吗？后续变化是否会重复前一轮？
7. 它是否符合已经核验的平台要求？有哪些仍需查证或由创作者确认的风险？

初次策划时可提出少量有区别的方向，并解释每个方向牺牲或增强了什么。方向比较不能替作者决定价值观、人物本性和结局取向。

## 商业可行性结论模板

- 灵感原貌：
- 题材与目标读者（如为假设，标为待验证）：
- 核心读者承诺：
- 最强的开篇钩子：
- 可持续冲突引擎：
- 连载空间与阶段兑现：
- 最有辨识度的元素：
- 番茄规则与作品条件（来源、日期）：
- 有依据的判断：
- 尚未验证的推断：
- 主要商业风险：
- 保留作者核心的调整选项：
- 需要创作者审核的内容：

**边界**：公开榜单、样书和规则可以帮助形成假设，不能代表平台内部推荐算法。任何收益、签约、推荐和改编结果均不作保证。
