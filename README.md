# 番茄网文商业化创作 Skill

**Tomato Novel Creator** 帮助创作者把故事灵感发展成适配番茄平台商业运作的完整网文：梳理创意、推演剧情、评估读者与平台适配、建立全书方案，再持续辅助写作和整书修改。

## 适合谁

- 手里有一个故事灵感，但需要把人物、冲突和后续剧情推演清楚
- 想在动笔前判断题材、卖点、读者承诺和连载空间
- 希望 AI 能在尊重作者核心设定的前提下，连续协助完成长篇小说
- 需要查询番茄当前的作品发布、签约、推荐、收益或内容规则

## 能力

- **灵感梳理**：保留作者原意，识别题材、人物、冲突、情绪价值与创作边界
- **商业适配**：贯穿选题、人物、剧情、章节和发布环节分析读者价值、追读动力、平台规则及执行风险
- **剧情推演**：比较不同发展方向，说明人物选择、冲突升级、代价、后果和阶段兑现
- **两道创作者审核关**：作者确认故事核心，再确认全书走向；确认后可连续协助创作，不逐章打断
- **全书协作**：生成分卷与章节规划、维护设定和时间线、撰写及修改正文、检查整书连贯性
- **规则核验**：优先引用番茄官方页面，区分官方规则、市场信号、经验和推断

Skill 不声称掌握平台内部推荐算法，也不保证签约、流量或收益。

## 安装到 Codex

1. 下载本仓库，解压。
2. 将仓库文件夹放入个人 Skills 目录：~/.codex/skills/tomato-novel-creator/。如果使用 CODEX_HOME，放到该目录下的 skills/tomato-novel-creator/。
3. 在 Codex 中输入 $tomato-novel-creator，或直接描述你的故事灵感与需要。

更新时用新版本覆盖已有 Skill 文件，并重新开启 Codex 对话以加载更新内容。

## 使用示例

- “我有一个被裁员的客服继承猫咖的故事灵感。先帮我拆核心冲突、目标读者和番茄商业适配，再推演三种后续方向。”
- “这是我确认的故事核心与人物设定。请按番茄读者追读逻辑推演全书大纲，重点评估连载空间和中段风险。”
- “我确认这个全书走向。请按每章的目标、冲突、人物选择、回报和续读动力持续写下去，并维护设定表。”
- “帮我实时核验番茄目前的签约和推荐规则，给出官方链接和核验日期。”

## 推荐文案

有故事灵感，却卡在后续剧情和整本书怎么落地？这个 Skill 会先陪你推演读者承诺、番茄平台商业适配和剧情空间；确认故事核心与全书走向后，再连续协助完成大纲、章节和整书修改。规则链接、题材套路和写作模板都在仓库里。

## 平台规则更新说明

平台条款、推荐门槛、活动和作者额度会变化。规则快照注明了页面日期与核验日期；发布或签约前，请再次打开官方页面和作者工作台确认。
